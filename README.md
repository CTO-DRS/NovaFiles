# 🌟 NovaFiles

**مدير ملفات أندرويد مفتوح المصدر** — منافس عصري وطموح لـ MiXplorer، مبني من الصفر بـ **Kotlin + Jetpack Compose + Material 3**.

<div dir="ltr">

`Kotlin 2.0` · `Jetpack Compose` · `Material You` · `minSdk 26` · `targetSdk 35`

</div>

---

## لماذا NovaFiles؟

MiXplorer تطبيق رائع لكنه مغلق المصدر وقديم الواجهة وقبل كل شيء **يتوقف تطويره**. NovaFiles يأخذ نفس قوة المفاهيم (خزنة مشفرة، سحابة موحدة، مشاركة متقدمة) ويعيد بناءها بواجهة Material 3 حديثة، بواجهة **عربية أولاً**، وبكود مفتوح يمكن لأي شخص تطويره.

| الميزة | MiXplorer | NovaFiles |
|--------|-----------|-----------|
| الواجهة | تصميم قديم | **Material 3 ديناميكي (Material You)** |
| المصدر | مغلق | **مفتوح 100%** |
| العربية | دعم جزئي | **RTL أصلي + تبديل لغة فوري** |
| الخزنة المشفرة | نعم | **نعم — AES-256-GCM + بصمة + PIN** |
| البحث الذكي | بحث بسيط | **فهرسة FTS فورية + مرشحات نوع/حجم/تاريخ** |
| مشاركة عبر WiFi | نعم | **نعم — خادم FTP مدمج بلا اعتماديات خارجية** |
| الوصول لخوادم الشبكة | SMB/FTP/SFTP/WebDAV | **نعم — عميل FTP + SFTP + SMB2/SMB3 بواجهة موحدة + حماية TOFU** |
| الأرشيفات | قراءة/إنشاء ZIP | **نعم — ZIP إنشاء+قراءة، و7z/TAR/RAR/GZ/BZ2/XZ قراءة واستخراج بحماية Slip** |
| وضع الجهاز اللوحي | لوحتان | **نعم — لوحتان مستقلتان بنمط iPad مع إرسال مباشر بين اللوحتين** |
| التطوير | متوقف تقريباً | **مجتمع نشط على GitHub** |

## ✨ ما المُنفَّذ الآن (v0.10.0)

### 🗂️ التصفح والعمليات
- تصفح التخزين الكامل بصلاحية «كل الملفات» (SAF مخطط له لاحقاً)
- عرض قائمة/شبكة مع صور مصغرة فورية للصور (Coil)
- ترتيب بالاسم/الحجم/التاريخ + إظهار/إخفاء الملفات المخفية
- تحديد متعدد (ضغط مطوّل) → نسخ / نقل / لصق / حذف آمن
- **سلة محذوفات**: الحذف ينقل إلى `.NovaFilesTrash` مع استعادة لاحقة
- إعادة تسمية، مجلد جديد، تفاصيل الملف، مشاركة وفتح بأي تطبيق

### 📱 وضع اللوحتين للجهاز اللوحي (v0.10.0)
- **لوحتان مستقلتان تماماً** تظهران تلقائياً عند عرض ≥ 600dp (iPad/تابلت أو هاتف بالعرض): كل لوحة بمسارها وتحديدها وعرضها (قائمة/شبكة) وترتيبها الخاص
- **إرسال بنقرة واحدة**: زر ⇄ في شريط التحديد ينسخ أو ينقل التحديد مباشرة إلى مجلد اللوحة الأخرى — بلا نسخ ثم تبديل ثم لصق
- **اللوحة النشطة** (الأحدث لمساً) بكامل الوضوح، والأخرى باهتة قليلاً بأسلوب iOS — وزر الرجوع يخدم النشطة أولاً
- فاصل شعري رفيع بين اللوحتين، وخط شريط Snackbar مشترك أسفل المنطقة، وكل شيء يتكيف مع RTL (اللوحة الأولى يميناً)
- **حماية جديدة في FileOps**: رفض نقل/نسخ مجلد إلى نفسه أو داخل أحد فروعه (خطر عودية لا نهائية في النقل الاحتياطي) — 10 اختبارات JVM جديدة
- **14 اختباراً جديداً** (المجموع 64): حماية النقل الذاتي + سياسة التخطيط النقية

### 🔍 بحث ذكي (النسخة الأولى)
- بحث فوري أثناء الكتابة مع خصم زمني (debounce)
- مرشحات: **النوع** (صور/فيديو/صوت/مستندات/أرشيفات/APK) + **الحد الأدنى للحجم (MB)** + **حدث خلال آخر (يوم)**
- بث النتائج تدريجياً حتى 1000 نتيجة مع إلغاء فوري

### 🔐 خزنة مشفرة (تشفير على مستوى البنوك)
- تشفير **AES-256-GCM** بمفتاح محمي داخل **Android Keystore** (غير قابل للتصدير)
- فتح بقفل **PIN** مملّح ومجزّأ SHA-256 أو **بالبصمة/الوجه** (BiometricPrompt)
- ملفات مشفرة بصيغة `.nvf` داخل مجلد مخفي — الأصل يُحذف بعد التشفير
- فك التشفير إلى أي مكان تختاره عبر منتقي المستندات

### ⭐ المفضلة + محرر وعارض
- مفضلة محفوظة في قاعدة بيانات **Room** مع حالة مباشرة
- **محرر نصوص** مدمج (txt/md/كود، حد 1MB) بخط أحادي المسافة
- **عارض صور** بتكبير حتى 8x بالإصبعين وتحريك حر

### 🌍 تدويل كامل
- عربي أولاً (RTL أصلي) + إنجليزي كامل — تبديل فوري من الإعدادات
- ألوان ديناميكية من خلفية النظام (Android 12+) مع Light/Dark

### 📡 مشاركة عبر WiFi (خادم FTP مدمج)
- خادم FTP **مكتوب من الصفر بلغة Kotlin بلا أي اعتمادية خارجية** (RFC 959)
- خدمة أمامية بإشعار دائم تعرض رابط الوصول، وتبقى حية أثناء العمل
- وضع Passive (PASV) وActive (PORT) — يعمل مع FileZilla ومستكشف Windows وcurl
- مصادقة باسم مستخدم/كلمة مرور + منفذ قابل للتعديل + حصر صارم في الجذر المشترك (حماية من `../`)
- قوائم بنمط Unix، رفع/تنزيل ثنائي، إعادة تسمية، حذف، استئناف تنزيل (REST)
- اختبارات وحدة JVM شاملة (11 اختباراً) تعمل على CI مع كل دفع

### 🌐 الاتصال بالخوادم (عميل FTP + SMB)
- **عميل FTP** (Apache Commons Net 3.11): اتصال بأي خادم FTP — نمط Passive، ترميز UTF-8 كامل للأسماء العربية، MLSD ثم fallback إلى LIST، نمط ثنائي صحيح (TYPE I بعد الدخول)
- **عميل SMB2/SMB3** (مكتبة SMBJ 0.13): مشاركات Windows وSamba وNAS — مصادقة NTLM، مجال اختياري، دخول مجهول/guest، تسجيل دخول آمن بجلسات SMB3
- **واجهة RemoteFs موحدة**: نفس الشاشات تعمل فوق البروتوكولين — سرد، تنزيل، رفع، حذف، إعادة تسمية، مجلد جديد
- **اتصالات محفوظة** في Room: اسم/بروتوكول/خادم/منفذ/مشاركة/بيانات دخول + اختبار اتصال فوري قبل الحفظ
- **متصفح بعيد بنمط iOS**: تنقل بالمجلدات، تنزيل إلى `Download/NovaFiles` مع تقدم مباشر، رفع من الجهاز (منتقي المستندات)، أوراق إجراءات للحذف/التسمية
- إعادة اتصال تلقائية عند انقطاع الجلسة + قفل Mutex يمنع تعارض عمليات النقل
- 10 اختبارات JVM جديدة: عميل FTP الحقيقي ضد خادمنا المدمج (دائري كامل رفع/تنزيل/تسمية/حذف بأسماء عربية)

### 🔑 عميل SFTP — نقل مشفّر كامل (v0.9.0)
- **بروتوكول SFTP فوق SSH** (مكتبة sshj 0.38): اتصال بأي خادم OpenSSH أو Dropbear أو استضافة مشتركة — نقل مُشفّر بالكامل ببقية المنظومة
- **توثيق مرن**: كلمة مرور مع سقوط تلقائي إلى keyboard-interactive (يكفي لخوادم OpenSSH التي تعطل «password»)
- **حماية «الثقة بأول استخدام» (TOFU)**: بصمة مفتاح الخادم (SHA-256 بأسلوب OpenSSH) تُحفظ محلياً عند أول اتصال ناجح — وإذا تغيّر المفتاح لاحقاً يُرفض الاتصال فوراً (كشف هجمات الوسيط)
- **بروتوكول ثالث في نفس الواجهة**: مفتاح منقسم ثلاثي FTP / SFTP / SMB في نموذج الاتصال، منفذ افتراضي 22، وأيقونة مفتاح بنفسجية iOS في قائمة الاتصالات
- **كل عمليات RemoteFs**: سرد بالترتيب الذكي، تنزيل بتقدم بالبايتات، رفع، حذف **تكراري للمجلدات** (البروتوكول يمنع حذف غير الفارغ)، إعادة تسمية، مجلد جديد
- إعادة اتصال تلقائي عند الانقطاع + تنظيم صارم للموارد (لا تسريب مقابس عند فشل الاتصال) + أسماء عربية UTF-8 سليمة
- **13 اختبار JVM جديد** (المجموع 50): عميل SFTP الحقيقي ضد **خادم SSH مدمج** (Apache MINA sshd) — رحلة كاملة بأسماء عربية + رفض كلمة مرور خاطئة + اختبارا TOFU (تذكّر المفتاح ورفض المفتاح المتغيّر)

### 🗜️ أرشيفات شاملة (v0.7 + v0.8)
- **عارض أرشيف مدمج**: لمس أي ملف مدعوم يفتحه داخل التطبيق — سرد المحتويات مع أيقونات وأحجام، وملخص (ملفات/مجلدات/الحجم المفكوك/بعد الضغط)
- **استخراج كامل** بزر واحد إلى مجلد باسم الأرشيف، مع **شريط تقدم حي** بالبايتات وإلغاء تعارض الاسم تلقائياً `اسم (2)`
- **ضغط إلى ZIP**: حدّد أي عدد من الملفات والمجلدات → زر الضغط في شريط التحديد → أرشيف جاهز (مسارات نسبية، تداخل كامل)
- **استخراج هنا** من ورقة إجراءات iOS لكل أرشيف مدعوم
- **أسماء عربية UTF-8 سليمة** في الإنشاء والاستخراج (ترميز صريح `Charsets.UTF_8`)
- **حماية Zip-Slip**: رفض مدخلات `../` والمسارات المطلقة وبادئات محركات الأقراص (`C:\`) — تطبيع canonical وإجبار الوجهة
- محرك خالص من الاعتماديات (`java.util.zip`) + **8 اختبارات JVM**: رحلة كاملة عربية متداخلة، سرد، رفض zip-slip، تطبيع المسارات المطلقة، تقدم، رفض مصادر فارغة، منع تضمين الأرشيف لنفسه، كتابة فوقية

### 📦 صيغ موسعة: 7z / TAR / RAR / GZ / BZ2 / XZ (v0.8.0)
- **7z كامل** (Apache Commons Compress 1.26): قراءة واستخراج أرشيفات 7-Zip بضغط LZMA/LZMA2 مع تقدم بالبايتات (المشفر بكلمة مرور يُرفض برسالة واضحة)
- **عائلة TAR كاملة**: `.tar` و`.tar.gz/.tgz` و`.tar.bz2/.tbz2` و`.tar.xz/.txz` — فك تلقائي للطبقة ثم قراءة الأرشيف
- **RAR (v4)** عبر junrar 7.5.5: قراءة واستخراج مع أسماء Unicode (`fileNameW`)، وكشف صريح للأرشيف المشفر، ورفض RAR5 تلقائياً من المكتبة (دعم RAR5 مرشح لإصدار قادم)
- **ضغط أحادي الملف**: `.gz` / `.bz2` / `.xz` — استخراج إلى الملف الأصلي باسمه منزوع الامتداد، بتقدم غير محدد (الحجم الأصلي مجهول قبل الفك)
- **موزع موحد `ArchiveEngine`**: نفس شاشة العارض وورقة الإجراءات تعمل على كل الصيغ — `supports()` لتمييز ما يُفتح داخل التطبيق تلقائياً
- **حاجز Slip مشترك** (`ArchiveSafety`): نفس حماية Zip-Slip مطبقة على TAR/7z/RAR (مختبرة ضد `../`)
- **8 اختبارات JVM جديدة** (المجموع 37): رحلات TAR وTAR.GZ و7Z بأسماء عربية، رفض Tar-Slip، استخراج gz أحادي، توزيع الموزع، نزع الامتدادات المركبة، واستمرار مسار ZIP

## 🚀 التشغيل والبناء

> المتطلبات: **Android Studio Ladybug أو أحدث** + **JDK 17**

1. استنسخ المشروع أو فك ضغط `NovaFiles.zip`
2. افتح المجلد في Android Studio (سيكتشف Gradle 8.9 تلقائياً)
3. انتظر المزامنة الأولى ثم اضغط ▶️ Run

أو من سطر الأوامر:

<div dir="ltr">

```bash
./gradlew assembleDebug        # بناء نسخة تجريبية
./gradlew installDebug         # تثبيت على جهاز متصل
./gradlew assembleRelease      # إصدار نهائي
```

</div>

> ملاحظة: أول بناء ينزل التبعيات (~2-3 دقائق). المشروع لا يحتاج أي مفتاح API أو إعداد خاص.

### الصلاحيات المطلوبة
- **كل الملفات** (MANAGE_EXTERNAL_STORAGE): لتصفح وإدارة الملفات — تُمنح يدوياً من إعدادات النظام عند أول تشغيل، ولا يرسل التطبيق أي بيانات للإنترنت.

## 🏗️ المعمارية

نمط **MVVM** مع طبقات نظيفة وManual DI خفيف — التفاصيل الكاملة في [ARCHITECTURE.md](ARCHITECTURE.md):

```
com.novafiles.app/
├── core/        منطق الأعمال النقي (ملفات، بحث، خزنة، صلاحيات، شبكة FTP/SFTP/SMB، أرشيفات ZIP/7z/TAR/RAR)
├── data/        قاعدة البيانات (Room) والإعدادات (DataStore)
├── ui/          واجهات Compose + ViewModels (متصفح/بحث/خزنة/شبكة/...)
└── util/        أدوات مساعدة (مشاركة، أيقونات، تنسيقات)
```
